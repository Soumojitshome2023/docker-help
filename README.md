# Docker Reference & Learning Hub

Welcome to the **Docker Reference & Learning Hub**. This repository serves as a structured documentation space to help you learn Docker and keep useful helper commands handy.

## 📂 Repository Structure

The documentation is organized into two primary sections:

1. **[Helper Commands](./commands/README.md)**: A cheat-sheet style collection of daily-use and advanced helper commands for containers, images, volumes, networks, and system cleanups.
2. **[Learning Guide](./learning/README.md)**: A step-by-step conceptual guide covering Docker architecture, Dockerfile best practices, multi-stage builds, persistent storage, networking, and Docker Compose.

---

## 🚀 Quick Start with Docker

To check if Docker is installed on your system and running properly, open your terminal and run:

```bash
# Check Docker version
docker --version

# Check Docker system-wide information
docker info

# Run a test container to verify setup
docker run hello-world
```

For more helper commands, navigate to the **[commands/README.md](./commands/README.md)** guide.
For deep-dive topics, check the **[learning/README.md](./learning/README.md)** guide.
